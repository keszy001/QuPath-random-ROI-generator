# QuPath Analysis Script for _Amygdala vulnerability in Pick disease with discrete frontotemporal dementia syndromes_ (Keszycki et al., 2026, Brain Pathology)

## Requires QuPath v0.4.0 or higher

## To use:
1. Open QuPath and load your image\
2. Automate --> Script Editor
3. Run random_ROI_square_generator.groovy

## This script creates 250 x 250 µm squares to place randomly inside a selected ROI without overlap. You can change the number of squares to place inside the script based on the percentage of tissue you'd like to cover.
